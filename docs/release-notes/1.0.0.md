WSF 1.0.0 is the first release of WSF. WSF rips Nintendo Wii sequenced music into a PSF-family format and plays it with the game's AX microcode on an emulated GameCube/Wii DSP. The release comes with a ripper (`wsfrip`), a renderer (`wsfplay`) and a foobar2000 component. `docs/wsf.md` describes the format.

The programs run on Windows 10 or later and require no runtime DLLs. To install the component, open the file with foobar2000, or add it under Preferences › Components. For other systems, the README explains how to build from source.

## Features

- **Ripping.** `wsfrip` rips a Wii disc image (ISO, NKit, RVZ, WIA, GCZ, WBFS, CISO or WDF), an extracted disc, or a sound archive (`.brsar`, with a game's `main.dol` for AX's microcode). It creates a `.wsflib` and a `.miniwsf` for each sequence. The game partition must be stored decrypted. NKit, RVZ and WIA images store it that way. Dolphin converts other images to RVZ without losing data. `wsfrip` plays each sound to determine its length and fade tags. `--bgm` rips only the music. Drag and drop also works.
- **Two rip modes.** Game mode runs the game's sound code on an emulated Wii. The rips play as the game does. Game mode requires a driver profile for the game. Wii Sports, Wii Play, WarioWare: Smooth Moves, Mario Kart Wii, Wii Music and Animal Crossing: City Folk (all USA) have one. Archive mode plays a sound archive from any game with WSF's model of the SDK's sound player. The model follows the 2007 and 2008 versions of the sound library.
- **The game's mixing.** In both modes, the game's AX microcode runs on an emulated DSP. The mixing, filtering and resampling therefore match the console.
- **Rendering.** `wsfplay` renders rips to WAV or FLAC at the Wii's rate of 32,000 Hz.
- **foobar2000.** The component plays `.miniwsf` files with their length and fade tags. It supports tag editing, ReplayGain and endless playback. It renders ahead of playback on a separate thread and saves the emulation's state as it goes. Seeking back is instant. Seeking forward only waits for rendering to reach the target.

## Known limitations

- Archive mode's model follows the versions of the sound library in Wii Sports (2007), Mario Kart Wii (March 2008) and Wii Music (June 2008). A game with another version may play differently from the console. The newest version can put biquad filters on a track's notes. Archive mode applies the library's preset filters. It doesn't apply a filter that a game defines in its code. Some games' AX microcode is too old for the model to drive at all. Those games can only be ripped in game mode. Game mode requires a profile for the game.
- Sounds that play until the game stops them, such as ambiences, get two loops and a fade when the ripper can find their loops. Otherwise they play until their notes end, for at most ten minutes.
- Only sequences are ripped. Use tools such as vgmstream for BRSTM streams. Wave sounds, and sequences whose data the game can't load, are skipped.
- The output is the TV's stereo mix. The Wii Remote speaker's sounds and surround aren't played.
- Encrypted disc images aren't read.
